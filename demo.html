دليل استخدام مكتبة monopix

مكتبة JavaScript / TypeScript سريعة وخفيفة لتوليد الصور الرمزية بالبكسل مع دعم الحروف العربية واللاتينية ومخرجات متعددة بدون أي اعتماديات خارجية.

1. التثبيت (Installation)

TERMINAL 
npm install monopix

2. البداية السريعة (Quick Start)

TYPESCRIPT / ESM 
import { createAvatar } from 'monopix';

const avatar = createAvatar({
  name: 'Ahmed',
  size: 160,
  options: {
    gridSize: 7,
    color: '#BFFF00',
    background: '#0A0E0A',
    shape: 'square',
    pixelShape: 'square'
  }
});

const svg = avatar.toSVG();       // SVG markup string
const uri = avatar.toDataURI();   // Data URI for <img src="...">

3. استخدام CommonJS

JAVASCRIPT / NODE.JS

6. تسجيل نمط مخصص (Custom Mode)

TYPESCRIPT 
import { registerMode, createAvatar } from 'monopix';

registerMode('badge', (name, size) => {
  const char = name.charAt(0).toUpperCase();
  return {
    char,
    grid: [[true]],
    svg: `<svg viewBox="0 0 ${size} ${size}"><text>${char}</text></svg>`
  };
});

const avatar = createAvatar({ name: 'Watheek', mode: 'badge' });
